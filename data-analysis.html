一、课程概述 & 基础理论

  • 数据分析定义、发展与行业应用
  • 数据分析完整工作流程：采集 → 清洗 → 分析 → 可视化 → 报告
  • 基础统计学：均值、中位数、众数、方差、概率基础
  • 数据分类、数据质量判断与数据清洗原则

课后习题（理论）

  1. 简述数据分析的完整流程，并说明数据清洗的作用。
  2. 举例说明均值、中位数、众数三者的区别与适用场景。
  3. 说一说日常生活中哪些场景用到了数据分析？

二、Excel 数据分析实操

  • 单元格操作、数据录入与格式规范
  • 常用函数：逻辑函数、统计函数、查找引用函数
  • 数据排序、筛选、分类汇总
  • 数据透视表、透视图综合运用

课后习题（Excel）

  1. 使用 SUM、AVERAGE 函数计算下表总分与平均分。
  2. 利用筛选功能，筛选出成绩大于85分的学生。
  3. 根据表格数据，制作数据透视表，统计各分数段人数。

示例学生成绩表

姓名 语文 数学 英语
张三 86 92 78
李四 79 81 88
王五 90 85 93

三、SQL 数据查询

  • 数据库基础、数据表结构认知
  • 基础查询、条件筛选、排序与限制结果
  • 分组统计、聚合函数使用
  • 多表连接、子查询综合练习

基础代码示例

-- 1. 查询所有学生信息
SELECT * FROM student;

-- 2. 查询数学成绩大于80分的学生
SELECT name, math FROM student WHERE math > 80;

-- 3. 统计班级总人数
SELECT COUNT(*) AS 总人数 FROM student;

课后习题（SQL）

  1. 查询英语成绩高于90分的学生姓名与分数。
  2. 使用聚合函数计算全班数学平均分。
  3. 将所有学生成绩按语文分数从高到低排序。

四、Python 数据分析入门

  • Python 基础语法、环境搭建
  • Numpy 数组运算
  • Pandas 数据读取、清洗、转换、统计分析

基础代码示例

# 导入数据分析库
import pandas as pd
import numpy as np

# 读取表格数据
df = pd.read_excel("成绩表.xlsx")

# 查看数据基本信息
print(df.describe())

课后习题（Python）

  1. 使用 Pandas 读取 Excel 成绩表，并输出前5行数据。
  2. 计算三科成绩各自的最大值、最小值。
  3. 对缺失数据进行简单清洗处理。

五、数据可视化

  • 各类图表适用场景与选择规则
  • 使用 Excel / Python 绘制专业图表
  • 图表解读、数据观点提炼

课后习题（可视化）

  1. 根据学生成绩表，使用柱状图对比三位同学总分。
  2. 简述折线图、饼图、散点图分别适合展示什么类型数据。

六、综合实战 & 课程作业模板

📝 课程大作业：学生成绩数据分析报告

作业要求：基于上方成绩数据表，完成完整数据分析并撰写报告

作业结构模板（直接套用）

  1. 一、分析背景与目的

    本次针对班级学生三科成绩开展数据分析，了解整体学习情况、分数分布，为学习总结提供数据支撑。

  2. 二、数据说明

    数据源：班级学生语文、数学、英语成绩表，共3条样本数据。

  3. 三、数据处理过程

    1. 数据录入与整理 2. 数据清洗（检查异常值、空值） 3. 计算总分、平均分

  4. 四、数据分析结果

    展示统计数据、图表，并解读数据特征。

  5. 五、结论与建议

    根据分析结果总结问题，并给出合理建议。

作业提交要求

  • 包含原始数据表、计算过程、可视化图表
  • 报告排版整洁，逻辑清晰
  • 可附 Excel / SQL / Python 操作截图
