一、课程概述 & 基础理论

  • 数据分析定义、发展与行业应用
  • 数据分析完整工作流程
  • 基础统计学知识：描述性统计、常用统计量
  • 数据分类、数据质量判断与数据清洗原则

二、Excel 数据分析实操

  • 单元格操作、数据录入与格式规范
  • 常用函数：逻辑函数、统计函数、查找引用函数
  • 数据排序、筛选、分类汇总
  • 数据透视表、透视图综合运用

三、SQL 数据查询

  • 数据库基础、数据表结构认知
  • 基础查询、条件筛选、排序与限制结果
  • 分组统计、聚合函数使用
  • 多表连接、子查询综合练习

四、Python 数据分析入门

  • Python 基础语法、环境搭建
  • Numpy 数组运算
  • Pandas 数据读取、清洗、转换、统计分析

五、数据可视化

  • 各类图表适用场景与选择规则
  • 使用 Excel / Python 绘制专业图表
  • 图表解读、数据观点提炼

六、综合实战与报告撰写

  • 真实数据集综合分析练习
  • 问题定位、数据分析、结论推导
  • 标准数据分析报告结构与写作规范
